# Agent Remote iOS

界面采用 iOS 系统背景色，浅色和深色外观都使用自适应的墨绿色主题色。任务完成并收集到可预览产物后，网关会额外请求一次 Agent，根据已完成结果与产物名称生成供动态展示的 `cover.svg` 和简短介绍。生成使用独立临时会话，限时 60 秒，期间可以继续追问原会话。封面沿用鉴权和离线预览，仅在网关内存中保存至服务重启；生成失败时显示原产物。此过程会使用所选 Agent 账号的额外模型额度，需要同时更新网关和 App。

[English](README.md) · [电脑接入服务安装说明](../README_ZH.md)

先在包目录执行 `npm ci && npm run build`，再执行：

```sh
cd ios
xcodegen generate
open QwenLiveMobile.xcodeproj
```

选择自己的开发团队和已信任的 iPhone，点击 Run。显示名称为 Agent Remote。为了升级时保留已有配对，Bundle ID、配对链接协议和钥匙串标识沿用旧值；覆盖安装旧 App 时不要重命名这些标识。

原生 SwiftUI 的四个标签依次为 **助手 → 工作台 → 动态 → 我的**。助手直接呈现 Omni Live，点击“开始对话”即可语音交流；尚未配置 Key 时显示“设置语音对话”。打开页面不会自动录音。右上角可进入设置，模型信息、隐私和诊断放在“关于语音对话”中。离开助手页或进入后台会结束通话。之前保存的输入仍可在“动态”和“我的”查看；旧版助手未保存的草稿可在“我的 → 已保存的输入”中检查并保存。

动态不设分类筛选，展示实际任务结果、产物引用与本机保存的输入。产物预览沿用现有的 HTTPS 证书固定与离线渲染校验。“我的”提供外观、语音语言、本机输入管理、任务结果收藏、电脑管理与隐私说明。没有数据时显示空状态，不填充示例成果。Omni Live 支持直接语音对话；长期记忆、每日总结、主动通知与 Live 任务派发尚未接入。

在工作台底部直接输入，发送后创建会话，无需先打开新会话页面。点项目旁的“＋”会选择该目录并聚焦同一个输入框，点输入框上方的目录与 Agent 可更改运行设置。切换标签保留未发送的草稿；电脑确认收到第一条消息，并同步对应任务后，自动进入会话继续追问。补充要求沿用同一个 Agent 会话，每轮分别展示结果、授权和停止状态。动态中的任务链接会校验电脑、上下文、服务运行及任务身份。草稿继续按电脑、服务运行和会话隔离。多轮会话需要同时更新电脑接入服务；电脑服务重启后不会恢复旧会话。

iOS 26 及以上的工作台和会话页输入栏使用系统 Liquid Glass 材质。工作台麦克风将语音转成可编辑的任务文字，不会自动发送。点击时才申请麦克风与语音识别权限，要求设备支持对应语言的本机识别。离开页面、切换电脑或服务运行、App 不活跃时都会停止听写。发送前可检查文字，不保存录音文件。

任务结束后，运行耗时会固定下来。点击每轮回复下方的“产物”，可预览图片、Markdown 和静态 HTML。预览需要同时更新接入服务和 App；支持的文件与限制见[接入服务说明](../README_ZH.md#ios-app)。

从工作台输入框上方的“运行设置”，或已有会话的输入区打开“工作文件夹”，可浏览共享根目录和子目录、返回上一级、搜索已加载的目录名称，并确认“使用此文件夹”。选择按电脑分别记住，新 Agent 会话会以该目录实际运行。在已有会话中选择其他目录会返回工作台输入框准备新任务，原会话及其草稿保持原目录。仅能浏览电脑端 App 或 `--project` 已共享的目录，符号链接不能跳出共享范围。旧网关仍可选择预先配置的目录。网关重启后，之前选择的子目录需要在发送前明确重新选择，草稿保持不变。

在工作台底部或追问输入框点击 **+**，可以从相册或“文件”选择图片，发送前可预览和移除，也可只发图片。每次最多 4 张，原图每张不超过 32 MB；App 会转换为最长边 2048 像素、每张不超过 2 MB 的 JPEG，不转发原始图片元数据。工作台通过已配对的 HTTPS 连接把实际图片内容传给声明支持图片输入的 Agent，需要同时更新电脑接入服务和 App。旧服务或不支持图片的 Agent 不会悄悄丢弃图片后只发文字。上传图片在本次服务运行期间可预览，总计最多保留 64 MB；重启服务会清除其内存副本。手机将图片文件与草稿元数据分开保存，当最后一个引用它的已保存输入、草稿或待确认请求被删除或确认接收时移除文件。待确认请求重试沿用相同图片内容和请求 ID。

### 使用自己的 Key 进行 Omni Live 通话

打开“我的 → Omni Live 设置”，或 Live 页面内的设置按钮。输入 DashScope API Key、对应的工作空间 ID 和地域（北京或新加坡），保存一次即可。Qwen3.8 使用工作空间专属端点，工作空间 ID 必须与 Key 的地域一致。Key 保存在 iPhone 系统钥匙串中，使用 `WhenUnlockedThisDeviceOnly`，不通过 iCloud 同步；不会打包进 App、发送给电脑接入服务或保存在偏好设置中。重新打开设置可替换或删除；删除本地记录不会撤销服务商处的 Key。

Live 无需配对 Mac。点击“开始对话”后，App 请求麦克风权限，通过系统校验的 TLS 将已保存的 Key 换成有效期 60 秒的临时 Key，再连接 `qwen3.8-omni-flash-realtime`。收到会话配置确认后才开始采集。若音频引擎在启动期间、尚未收到麦克风数据或播放回复时停止，Live 会在原有采集超时内重建一次音频连接，不重连对话或重播音频。诊断包含引擎状态、配置变化与启动恢复次数以及固定错误码。输入为 16 kHz 单声道 PCM16，输出为 24 kHz 流式音频，并显示双方字幕。静音停止上传音频；挂断、离开助手页、进入后台、音频中断或连接失败都会释放采集和播放。音量指示反映实际采集信号；连接后持续收不到麦克风数据会结束通话并提示。连接诊断只包含状态、音频格式和片段计数，复制时不包含 Key、音频或字幕。Debug 构建还会在 App 缓存中保留这一小份状态快照，供真机排障。音频和字幕只保留在内存中。摄像头、屏幕共享、工具和长期记忆尚未接入。网络失败会结束通话，需要手动重新连接以开始新会话。

模拟器测试示例：

```sh
xcodebuild -project QwenLiveMobile.xcodeproj -scheme QwenLiveMobile \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath build CODE_SIGN_IDENTITY=- CODE_SIGNING_ALLOWED=YES test
```

完整 TLS/UI 测试需要先在包目录运行 `npm run test:ios-fixture` 并保持运行，再重新生成 Xcode 项目。每轮重跑都需重启 fixture；没有 fixture 时相关测试会明确跳过。自动化使用替身，真机网络、扫码、签名与真实 Agent 执行需分别验收。

客户端强制 HTTPS、拒绝重定向，并校验已配对证书的指纹、地址、有效期和服务器用途。ATS IPv4 例外用于允许私有证书，不绕过上述校验；测试覆盖错误指纹和明文请求拒绝。
